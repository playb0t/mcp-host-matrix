# Claude Code: live tool view and selection gap

After manual login in an isolated profile, unchanged Claude Code 2.1.330 refreshed its native /mcp > own server > View tools list from keep/removed to keep/added while open in two passes. The client requested the new list after each notification. Reopening and a new managed CLI process also showed the current list.

The inspected server menu offers View tools, Reconnect, Disable in this project and Back. Enter on a tool opens its name and description. No individual availability selector was found there; application-wide absence is not established. Choice, confirmation and individual persistence remain not measured; permission rules were not used as a substitute.
